# draft (working name)

A compiler for group agreement. Input: a starting text, a roster, a constitution file. Output: the most-agreed text, plus a record of every disagreement, ranked and mapped.

- **[SPEC.md](SPEC.md)** — the specification (currently v0.5), source of truth for the mechanism.
- **[QUESTIONS.md](QUESTIONS.md)** — open clarifying questions; answers get folded into DECISIONS.md and spec revisions.
- **[CLAUDE.md](CLAUDE.md)** — project conventions and the glossary of named parts.

Status: pre-build. Spec under clarification; phase plan agreed but not started.
