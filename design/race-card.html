      Design notes — the race-card, sixth pass: the overlay model

      Desktop-first · light mode · Bootstrap-plain (visual design deferred) · card content from run clubhouse-1

      The document is the status quo, and it stays still

      The page shows exactly one text: the current document — not the session's starting text, the text as it stands right now, adoptions included. It never reflows. Races are overlays: picking one from the queue moves a highlight onto the contested span and attaches candidate panels beneath it; switching races just moves the highlight. The status quo is no longer a "version" competing for a lane — it is the ground everything else is judged against, which is what it actually is in the mechanism.

      The triad, resolved case by case (Ed, point 6)

      • Challenger vs current: the current text is the highlighted ground; the proposal is one overlay beneath it. The right-hand verdict is "Keep the current text." No status-quo card, no status-quo rationale — the ground needs no pitch.
      • Rival vs rival: the ground stays visible (highlighted, labelled "current text — both proposals replace this"), both overlays sit beneath it, and the prompt asks the honest conditional question: "if this text changes, which change is better?" There is deliberately no keep-current verdict here — that signal belongs on incumbent cards, which the router owes any judge who leans status-quo, and rival cards are only served once the race shows evidence that at least one challenger plausibly displaces the incumbent (SPEC §8.3, Ed 2026-08-14).
      • Propose C: the composer opens seeded from the contested span, with "start from the current text / from A / from B" — C in context of all three, as it should be.
      • The status quo moves during the session: true, and the overlay model makes that legible instead of confusing — the ground you see is always today's ground, and when an adoption changes it underfoot, the gazette flashes and the engine has already staled the old evidence (incumbent identity is the hash of the current span text). The card you come back to is honestly different, and looks it.

      Navigating the race queue

      The queue is a sidebar, not a conveyor belt: every served card is listed with its location, kind, and a ✓ once judged; you take them in any order and revisit freely. Switching feels like flipping between transparencies laid over the same page. Verdict buttons stay sticky at the top with the rationales directly beneath them — read both arguments, then scroll the still document, vote whenever.

      Where dispute names come from (Ed, point 5)

      Honestly: the engine knows a dispute's location (its span and footprint), not its nature. The labels here use the nearest markdown heading plus an excerpt — which works because this charter has headings, and fails gracefully to line-position + excerpt when a document doesn't. Understanding what kind of dispute it is (typo vs constitutional matter) is an LLM classification job — P3 generates a name and a type per race (Q49), and the type should also inform routing: copy-edit races shouldn't burn attention-ranking slots. Diagonal cards inherit whatever naming exists; they never depend on section headings specifically.

      Comparison modes, inside the overlays

      • Marked up (default) — every overlay is a diff against the ground directly above it; since the ground is always visible, this is now the canonical mode.
      • Fair copy — the overlay as clean final text.
      • Differences (rival races only) — dims what the two overlays agree on, highlights in blue where they disagree with each other. Green/red = versus the ground; blue = versus each other.

      Discontinuous patches and new sections

      A multi-site patch highlights every site of its footprint and attaches an overlay at each, badged "change N of M"; one verdict speaks for the whole patch. A new-section patch shows a dashed insertion marker at its position in the ground with the proposed section as its overlay — and since the ground simply continues, absence needs no fake card. Deleting a section would be the mirror: the doomed span highlighted, an overlay reading "this section is removed."

      What is deliberately absent

      • No authors. Sealed until close; rationales labelled unsigned. Mo's spelling ships exactly as submitted.
      • No standings, counts, or direction. A/B order randomised per serve. Live-proposal counts on attention cards are public magnitude, never direction.
      • The bar is public, race evidence is not.
