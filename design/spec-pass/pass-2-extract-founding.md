```
title → slug → myemail → [magic link] → grant-pen → grant-shield (+ chamber beside it) → chamber → policy → hat → myname → mypic → roster → lapse → removal → ending → bar → quorum → authorship → signing → judgments → rate → machines → text → begin → [🍾] canpropose + canjudge + grant-voice (three at once) → (rail empty)
```

## 3. Rules (F1…)

Each carries where it is stated and where the code enforces it.

- **F1 The founding runs in single file, in the document's own order.** `ORDER` (`session-view.html:1863–1868`) is the dependency list; `orderReady` consults nothing else for the keys it names (`:1897–1904`). Stated: CLAUDE.md:144; SURFACE C14 (line 22); notes file retired the wave graph (`setup.notes.md:44–52`).
- **F2 The birth order is fixed: 🪶 → 📍 → 📧, and the magic link is the instantiation.** `ORDER[0..2]`; `myemail.dep = ['slug']`, `slug.dep = ['title']` (`:1226,1231`). Nothing is saved until the link is followed (SPEC §9.7a, line 288; CLAUDE.md:123, 126). The walk confirms: after *commit myemail (sends)* the rail still holds 📧; after *follow the magic link* it holds ✒️ alone.
- **F3 Each task is born as the one before it settles; a non-gate card blocks the file until settled.** `blocksOrder` (`:1894–1896`): `!p.isGate && !settled(p)`. `settled` (`:1740–1766`): `S.seen.has(k) && ready(c)`, then the module's `settledBy !== null` (or `holder === 'members'`).
- **F4 A gate or grant holds its place without blocking; the pen is the one grant that blocks.** `blocksOrder` first branch; reasoning at `:1869–1893`. SURFACE Y4 (line 82). 🛡️ explicitly does not block (`:1164–1180`). 🏛️ does not block (`:1889–1893`).
- **F5 The gate clauses (💡 ⚖️) wait for 🍾.** `hide: () => !constituted()` on both (`:1116,1123`). SURFACE Y5 (line 83); CLAUDE.md:145; Q529. Consequence measured in the walk: 🍾 is the only step that delivers more than one clause (`begin` already stood; 💡 ⚖️ 🏛️ arrive together).
- **F6 🍾 is the founder's and invisible to members before the start.** `hide: () => !amFounder() && !constituted()` (`:1181`); `mustAct` = `amFounder() && !constituted()` (`:1776`); a member sees it `waiting` (`:2879`). Its card states the batch (`BEGIN_BATCH`, `:6239–6244`) and the readiness readout (per question, per person — `beginBody`, `:6245–6266`), which informs and never blocks except the judge-gate hold (*The document cannot begin while 🌍 Visibility is still being decided.*).
- **F7 Nothing is pre-answered.** `CHOSEN` (`:1715–1732`) per setting; `ready(c)` = `c.ready ? c.ready() : chosen(c.k)`; `chosen(k)` = `wantsDelegate(k) || !CHOSEN[k] || CHOSEN[k]()` (`:1733`). The commit stays dark until the predicate is true. The hat's radio preselects nothing until answered once (`:3515`). The old defaults survive only in ⏩'s `SEED` (`:2780–2803`). CLAUDE.md:147.
- **F8 Typing into a rung's own field is choosing that rung.** Encoded by the `CHOSEN` predicates: `lapse: 'never' || (lapse && isNum(lapseDays))`, `ending: 'perpetual' || (ending && endsAt)`, `quorum`, `machines`, `rate` (`:1722–1730`). CLAUDE.md:147.
