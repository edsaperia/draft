# Glossary — the engine and the tooling

The Engine and Tooling halves of CLAUDE.md's *Glossary — named parts*, moved here by Q1548 (Ed, 2026-09-26: *move half*); the Design system and Product halves, the Retired names and the Gotchas stay there. Use these names in all discussion, commits, and code, and read `design/DECISIONS.md` for the reasoning behind them.

**Every entry keeps CLAUDE.md's entry rule** (Q737): a name, a one-line job, a `[file|symbol|concept]` kind and pointers — nothing else, at any depth, and no entry past 400 characters. A rule, a reason or a post-mortem stuck to a name goes where CLAUDE.md's *What goes in this file* sends it. `npm run spec-check` holds the shape here as it does there.

**Engine (mechanism, no UI):**
- `engine-core` [symbol] — the session state machine: candidates, races, adoptions, the threshold ramp, tokens and refunds, adoption floors, certification. Pure TS, node-free and browser-loadable. Rules: SPEC §2–§8, §13. Adoption batching and the cooldown metronome: SPEC §4.2. Amendments binding races in flight: SPEC §4.3.
  - `packages/engine-core/src/routing.ts` [file] — the serving rules (SPEC §8) as `Routing` over a `RoutingHost` of live closures (Q1352 (o)); spec-check reads `bestPairFor` out of it.
  - `packages/engine-core/src/races.ts` [file] — races and their ranking (SPEC §2.3, §4.1) as `Races` over a `RacesHost` (Q1352 (p)); the `derived` memo stays in the session, keyed on the state version (Q1326). **`races(t)` reads the clock** since Q1439: `approvals` · `group` · `floor` move with no event, so the memo holds the time-free core. `pairGround` is a judgment's ground (Q1441).
  - `Session.memo` [symbol] — the two dev switches over that memo (Q1326, Ed 2026-09-14): `off` derives everything afresh, `audit` recomputes every hit and throws where cache and live state disagree; both off in every shipped path. Guard: `packages/engine-core/test/memo-differential.test.ts`.
  - `dominated-proposal` [concept] — **a proposal that can never win is closed** (Q1440, Ed 2026-09-18): no answer still to come could carry it; `dominations` (races.ts) finds it, `retireDominated` closes it with the adoption batch, the bridge holds a motion, the view keeps its record back while the clause races. SPEC §4.4, R-132; guard `dominated.test.ts`.
  - `re-aim` [concept] — **a rival covering a change stays in the race** (Q1534, Ed 2026-09-24): `carryHunks` picks the road, `planCarry` the judgments that carry, `candidate-reaimed` records both, settings at `setStanding`; the view reads `carried`, records split at each adoption. SPEC §2.4, §4.4, §9.6, R-141; guards `reaim.test.ts`, `legacy-replay.test.ts`, `rivals-stay.test.ts`.
  - `rival-measure` [concept] — **a leader passes only once measured against every live rival** (Q1538, Ed 2026-09-25): each pair answered by its own floor, or settled; a rival the batch will close is not waited on; waived at the close alone. `rivals` on the view, `clearsFloor` / `clearsAtClose` (races.ts). SPEC §4.2, §4.6, R-142; guard `rival-measure.test.ts`.
    - `measure-serving` [concept] — the router asks the pairs the leader waits on right after the decisive pair, once the rival gate is open or the leader has met its floor: `measureShort` on the view, the measure block in `bestPairFor` (routing.ts). SPEC §8.2, §8.3, R-142; guard `rival-measure.test.ts` A9.
  - `smith-set` [concept] — **the ranking is read inside the Smith set** (Q1539): the wordings reaching every other through measured head-to-head results, an unmeasured pair a gap, never a draw, the close included; empty, nothing carries. `smithSet` in `packages/engine-core/src/ranking/smith.ts`. SPEC §4.2, R-143; guards `smith.test.ts`, `rival-measure.test.ts`.
    - `smith-rank` [concept] — the field's order: the Smith set above the rest, the fit's order within each; what *the top of the ranking* and both domination guards read (`topOf`, `rankAbove` in races.ts). SPEC §4.2, §4.4, R-143; guard `dominated.test.ts`.
- `adoption-threshold` [symbol] — the engine's confidence bar, **pinned at 0.5 since SPEC v0.128 (Q1362, R-117) and deleted in pass 7**: adoption is the ranking's top once the floor is met, and this gates nothing. Formerly "θ"; always use this name. SPEC §4.2, §4.3.
- `patch-engine` [concept] — text machinery: diffs, footprints, three-way merge, rebase, surgery.
- `overlap-gates` [concept] — the three-gate classifier for colliding patches: textual composition → semantic composition → rivalry. SPEC §4.
- `ranking-model` [concept] — Bradley–Terry preference model per race, plus a global salience model, with active pair sampling and deadlock detection. SPEC §5, §8.
- `router` [concept] — feed ordering, hot set, exploration and salience streams, floors-aware serving, notification digests. SPEC §8.
- `event-log` [concept] — append-only hash-chained log, seeded RNG, participant receipts. SPEC §11.
- `dedup-gate` [concept] — submission-time duplicate check (embeddings, edit distance, LLM equivalence) plus behavioral dedup probes. SPEC §5.
- `race-labeler` [symbol] — advisory naming and typing of disputes, from the oracle's `describeRace` with a deterministic nearest-heading fallback. Outside the state machine: labels never enter the event log and gate nothing (Q49).
- `document-modes` [concept] — one setting fixed at creation: the **window** (an end datetime, or none); the threshold shape left with 🪜 (Q1362). SPEC §9.0. The surface asks the window on one card, ⏰, with *never* among its answers — SURFACE §8's `ORDER` table.
- `blind-founding` [concept] — the blind collection before any drafting (`founding-ceremony` until Q1243): each member states the lowest they will accept and the document takes the maximum of each. A consent rule rather than a vote, which is what lets it escape the constitutional bootstrap. SPEC §9.0a; the surface's order is SURFACE §8.
- `coherence-auditor` [concept] — machine drafter patrolling document drift on a fixed token budget. **Not a member**: it never judges and counts toward no quorum. No surface card since 2026-08-29 (backlog 251); the `machines` setting stays in the catalogue for replay, and a question delegated before the card went is resolved at 🍾 by its `retiredAnswer` (entry 259, R-080). SPEC §10.

**Tooling:**
- `phase-ladder` [concept] — **one dev control that walks a real document through its whole life**, a phase per press (Q674–Q678). Six rungs: `birth` · `constitution` · `ready` · `session` · `closing` · `closed`. Parts: `packages/server/src/dev-ladder.ts`, `dev-ladder-charter.ts`, the `ladder-bar`, and `npm run ladder`. Its design: `design/DECISIONS.md`.
  - `ladder-bar` [concept] — the control, off the design system like 📬 and for the same reason. Deliberately **not** a re-enable of `.devswitch`, whose seats are page state; here a seat **is** a cookie: every control is a POST and a reload. Bottom-left, where the stagehand lives.
  - `ladder-manifest` [concept] — **what is *in* the document at each rung**, printed by `npm run ladder` beside its assertions and naming the seat where a thing is seat-gated. Read back from the engine's own state and log, never the stagehand's report. `manifestOf` in `dev-ladder.ts`, served on `GET /api/dev/ladder`. Q1140–Q1142.
- `card-audit` [symbol] — **every decision card on every surface, opened and measured at once** (`design/tools/card-audit.mjs`, `npm run card-audit`). Its walks are `ALL_WALKS` in the script; `--walk=<name>` runs one. P13–P34 are the redesign's checks (`design/redesign/checks.md`), strict on every card under `--kinds=GRAMMAR_KINDS` since stage 10, P22 driven by real presses. It changes nothing.
  - `--baseline` [concept] — the second window size, and not optional discipline: a geometry finding that moves with the viewport is a layout fact, not a defect.
- `a11y-audit` [symbol] — **the surface read by the rules a keyboard and a screen reader go by** (`design/tools/a11y-audit.mjs`, `npm run a11y-audit`, `:narrow`, `--gesture=hold`): axe-core for the standard WCAG sweep, twelve hand probes for what is a fact about this surface, A16 driven by real key presses. A review, changing nothing. Findings: `design/REPORT-a11y.md`, Q1394–Q1398.
- `copy-check` [symbol] — **the words in seconds, the rendering behind `--walk`** (`scripts/copy-check.mjs`): static by default — `design/copy.js` against `copy-source.golden.json`, in `ci`; `--walk` the rendered cards against `card-copy.golden.json`, sprint tier, its raw-value rule at the push (`--raw-only`). Red until `npm run copy-freeze` (both goldens), whose diff a STYLE.md pass reads.
- `founding-golden` [symbol] — **the founder's order, rail and clause openings, frozen** (`scripts/founding-golden.mjs`, `design/tools/founding-walk.golden.json`): compared by `sprint.yml` on a push carrying a merge, never at a plain push (Q625, Q1546); `--update` re-freezes it as a batch closes.
- `qa-freeze` [symbol] — **the three references a batch moves, re-frozen in one command** (`scripts/qa-freeze.mjs`, `npm run qa:freeze`): the probes' `design/reference/` via `probe.mjs --update`, then the copy golden, then the founding golden. Run by plan-queue's freeze offer after each batch's QA; `pq freeze` makes the commit, never the script.
- `assert-server` [symbol] — **which server, is it a dev server, is it your tree?** (`scripts/lib/assert-server.mjs`): `walkBase`: argv, `DRAFT_BASE_URL`, `PORT`, 8140; then `/healthz`'s `devMail` must be true, so docs.vote is refused unwritten (issue #17); then the `build` sha against HEAD, else catalogue ids. All eleven attaching walks call it; the self-starting do not. Q911, Q917, entry 105.
- `scripts/ledger.mjs` [file] — **the three shared ledgers written to main byte-for-byte** (issue #179): a JSON input's CHANGELOG section, QUESTIONS block and *next free*, and DECISIONS section, each in its file's own line endings, refused on a spent number, a repeated heading or a mixed file; `--dry-run` prints the stat and the text. Guard `ledger.test.ts`.
  - `checkLineEndings` [symbol] — spec-check's rule that QUESTIONS.md, design/DECISIONS.md, CLAUDE.md and both session-view.html copies stay CRLF throughout (`LINE_ENDINGS`), red on a mixed or flipped file.
- `soak-harness` [concept] — **N clients against the real server at the same time** (`packages/sim-harness/src/soak.ts`, `npm run soak -w @draft/sim-harness`): real personas over the real HTTP login path, one cookie jar per seat, every command fired in one tick. Assertions, not metrics. Needs a dev server. Entry 77.
- `alpha-preset` [concept] — **the operating point at ten to twenty minutes** (`packages/sim-harness/src/alpha-preset.ts`, `npm run preset -w @draft/sim-harness`): whole candidate constitutions over roster × window, scored on `alive` — did the document change at all. The values and numbers: `PRODUCTION.md` § *Measurements*. Entry 77.
- `design/proposal/PLAN.md` [file] — `redesign-plan`, the surface redesign's phase one (Q1541, Ed 2026-09-25): a long autonomous run on branch `redesign` writing only under `design/proposal/`; its parts are `redesign-inventory`, `-diagnosis`, `-grammar`, `-mockups`, `-prototype` (`proposal/proto/`) and `-review`, the artifact holding questions 1541.n.
- `churn-study` [concept] — **does a peer status quo oscillate** (`packages/sim-harness/src/churn.ts`, `npm run churn -w @draft/sim-harness`): `flips` and `reversions` read off the engine's log, a room of fifteen over the three shapes' windows. The bar arm is a pinned null result and a guard; the floor is the brake. Findings: `packages/sim-harness/REPORT-churn.md`. Q1362 stage 5.
- `probe-coverage` [symbol] — **which cards the setup-probe actually opens** (`scripts/probe-coverage.mjs`, `npm run probe-coverage`): it runs the real probe and records every `data-setupcard` key that reaches the DOM, so coverage is measured by opening rather than by a selector naming something. A card in `ORDER` it never opens is a finding unless `EXEMPT` gives a reason. Q914.
- `picture-walk` [symbol] — **🖼️'s refusals, said out loud** (`design/tools/picture-walk.mjs`, `npm run picture-walk`, `--width=`): hands the uploader a file that is not a picture, one that only claims to be, 25 MB and a real one, and asserts what `.picnote` says about each. Serves `design/` itself, so it needs no server; in CI's `probe` job.
- `rate-motion` [symbol] — **a settings motion composed with real key presses** (`scripts/repro/member-rate-motion.mjs`, `npm run rate-motion -- <url>`, `--browser=`, `--only=`): sixteen scenarios on an nh2026-shaped document, the pill's cancel among them (`pill-cancels`); the only walk that types into a field composer. Q1486; in CI's `walks` job.
- `room-bots` [symbol] — **a room full of members who are not people** (`scripts/room-bots.mjs`, `npm run room-bots -- <url> [--key]`): seats every invitation to `*@bots.docs.vote` in the `bot-outbox` (`--key`, docs.vote too) or the `dev-outbox`; a bot judges, proposes on contested clauses (`--heat`, `--pile`), moves and OKs, legibly by temperament. Ed's UX instrument, 2026-09-06; not a walk.
- `news-walk` [symbol] — **the live-only news families, opened** (`scripts/news-walk.mjs`, `npm run news-walk`, Q1541 stage 2): a ladder document readied, 🍾 pressed keeping every power, then a release, a ✒️ amendment, a forced mail give-up and a ❌ over the wire; a member's page opens each card and reads its row and slots. CI's `doors` group, at 1600 and 390.
- `tap-outside-walk` [symbol] — **a card that asks nothing closes by a finger outside it** (`design/tools/tap-outside-walk.mjs`, Q1541 stage 2, 1541.8 (a)): the fixture at 390×844, touch on — the grants, the gates, 🍾 and a seen park each opened from its tab and closed by a tap on text; nothing opens in its place, nothing beneath is pressed. CI's `probe` job.
- `render-hold-walk` [symbol] — **nothing in the reader's hand is taken by a render** (`scripts/render-hold-walk.mjs`, `npm run render-hold-walk`, `--render=replace`, `--only=`): each in-flight kind on an open card under a forced poll and a room event, the node the same node, its state intact, the page still (principle 10, U1; redesign stage 9). CI's `repros-b`.
- `sweep-walk` [symbol] — **the wash sweeps on every vote in the rail, and the mark stamps** (`scripts/sweep-walk.mjs`, `npm run sweep-walk`, `--render=replace`): four seats, one under reduced motion; the rail's Web Animations read off `getAnimations()` beside `SESSION.sweeps` — the vote sweep, the endings, the stamp, a settings motion's entry (Q1571, SWEEP.md §2). `sprint-pages`.
- `presence-walk` [symbol] — **where each member is reading, served and drawn** (`scripts/presence-walk.mjs`, `npm run presence-walk`): three seats at 1600, one at 390; the dwell, the column's glide on the same node, the name as the title, 👀 and tokens under `sealed`, the phone drawing nothing, a closed page gone inside the TTL (Q1570, PRESENCE.md §2). `sprint-pages`.
- `load-walk` [symbol] — **a document loads on demand and unloads when idle** (`scripts/load-walk.mjs`, `npm run load-walk`): a close falling due while a document is unloaded, a push stream keeping one loaded, one load for six concurrent views and every view as it was after a reload (plan-scaling Stage 2). `sprint-motions`, on a server of its own.
- `push-walk` [symbol] — **a change reaches the other seat's page in under a second, an idle page asks for nothing** (`scripts/push-walk.mjs`, `npm run push-walk`): two seats on the stream; a proposal and a vote, an event kept under a held press, idle views against a `__noPush` page, push against the poll alone (plan-scaling Stage 4). `sprint-pages`.
- `room-walk` [symbol] — **the whole loop, live**: found → invite 15 → begin → propose → the new race askable of every member in their next view, dealt or by `ask` (Q1202) → adopt, twice; then the 🛡️ park-and-crown on a ladder document (`scripts/room-walk.mjs`, `npm run room-walk`). Needs a cooldown-0 server — the host default since R-086 — and refuses any other. Q1178, Q1179.
- `scripts/lib/walk.mjs` [file] — **the walks' shared hands** (refactor item 26): `say`, `sleep`, `arg`, `linkIn`, `outbox`, `post`, `followLink`, and the page helpers `typeIn` · `clickIn` · `open` · `openCard` · `press` · `pageGesture`, bound to one page with that walk's own timings by `onPage(page, defaults)`. A helper that differs on purpose stays in its walk. Asserts nothing.
- `seat-matrix.mjs` [file] — **N seats × the epochs, the rail asserted per seat against SURFACE §2's audience column** (`scripts/seat-matrix.mjs`, `npm run seat-matrix`). Three tables — `SEATS`, `STEPS`, `AUDIENCE` (a cell verbatim → a predicate) — and one `RUN` dispatcher. Its payload and the no-rule exit are the *seat matrix* convention below (Q1244). Entry 127.
- `server` [symbol] — `packages/server` (`@draft/server`): the thin product host, node:http, no framework, `npm run server` at the root. Live at docs.vote since 2026-08-20, CI deploying on green and verifying the live host afterwards. **A push is a deploy.** Operator docs: `docs/OPERATING.md` and `docs/runbooks/`; design reasoning: `packages/server/NOTES.md`.
  - `Persistence` [symbol] — two stores, one seam: `FilePersistence` is the JSONL layout, `PgPersistence` one row per log entry (`event` as `text`, never jsonb, which rejects NUL and lone surrogates), the `people` rows written beside the entries in one act. **The cutover is two variables**, `docs/OPERATING.md` §5, §7. Runtime dependencies: `pg`, and `@anthropic-ai/sdk` for the demo bots (Q1535).
  - `MaintainablePersistence` [symbol] — the maintainer's half of a store, the dumps and the two deletions, implemented by both backends and typed on the tools alone: nothing the server holds can reach a wipe (decision 1253).
  - `packages/server/src/views.ts` [file] — the two projections out of `server.ts` (Q1352 (k)): `raceView`, a member's blind text-race view, and `strangerView`, the door's; `admissionPrice` beside them. The contract is the server tests and the walks, over HTTP.
  - `packages/server/src/write-path.ts` [file] — the write path (Q1352 (l)): `WritePath` over exactly what `commit`, `relay`, `tellGaveUp` and `tick` read, and `PauseState`, since what a pause does is stop writing; the error counters stay in `server.ts`, reached only through `noteError`, so nothing points back.
  - `packages/server/src/routes.ts` [file] — the route table's ground (Q1352 (m), (n)): `RouteContext`, the per-request `Req` and its four guards, `Route` and `routeMatches`; the rows are `routes-admin/dev/auth/member/surface.ts`, concatenated as `ROUTES` in `server.ts` in the chain's own order, since that order is load-bearing; a dev row enters by a `DEV:`-labelled push so the build drops it.
  - `replay` [symbol] — one hash-chained JSONL log per document, and loading it is replaying it with its `people` rows handed in. **The log holds no identity; the rows do** — and it holds every answer in plaintext, so the data dir is as sensitive as the room. A log below schema version 2 is skipped at boot and named, never read (decision 1253).
  - `people` [symbol] — **identity beside the log, never in it** (`packages/constitution/src/people.ts`, decision 1253): a `PersonId` row per email, name and picture; events carry the id; records resolve through the row live, an erased person reading `erased: true` and null fields; `draft-tools people` · `erase` · `wipe` are the verbs. `docs/OPERATING.md` §5; guard `people.test.ts`.
  - `view` [symbol] — the only member read: the document as the engine holds it plus a blind projection of the text races — never standings, never an author, never anybody else’s judgments (§3.5). **A command whitelist injects the authenticated actor; a body never names who acts.** `tick()` each minute; every historical slug routes; one cookie per document. Guard: `spec-check`'s `checkCommands`.
  - `magic-link` [concept] — creation *is* the §9.7a mail, an invitation link arrives you (§9.6a), and revival is logging in. Stateless HMAC cookies.
  - `mail-fold` [concept] — Resend via `RESEND_API_KEY`, else `data/outbox.jsonl` and console; also the seam the `phase-ladder` is silenced through. **Reserved TLDs are refused at the mailer** (Q680) — `.invalid`, `.test`, `.example`, `.localhost`, and deliberately not the reserved second-level domains. A bot's address is redirected, not refused: `bot-outbox`.
  - `engine-host` [concept] — the engine rides every commit: the bridge born at constitute, `engine.jsonl` and `bridge.json` beside the log, resumed by replay (`engine-host.ts`).
  - `dev-outbox` [concept] — without `RESEND_API_KEY`, `GET /api/dev/outbox` serves the outbox tail and the page grows an off-system 📬 button. **In the production artifact the route does not exist at all** — the build drops its `DEV` label bodily; the one outbox that ships is the `bot-outbox`. A bot's mail lands in both, so `room-bots` reads either on a dev server.
  - `bot-outbox` [concept] — **mail to any address at `bots.docs.vote` is caught by the host, never sent** (Q1310, Ed 2026-09-10): `isBotAddress` files it in `bots-outbox.jsonl` in both mailer branches; `GET /api/bots/outbox` serves the tail to the bearer of `DRAFT_BOT_KEY` — 404 unset, 401 wrong — outside the `DEV:` label. `docs/OPERATING.md` §10; guard `bots.test.ts`, `verify-deploy`.
  - `notifyEmail` [symbol] — the operator hears about every birth: the save mails `cfg.notifyEmail` the title, the founder’s address and the URL, the one mail sent to somebody who is not a member. **Fired and forgotten: the save must never fail or wait on a mail.** `DRAFT_NOTIFY_EMAIL` overrides; empty switches it off.
  - `announced-pause` [concept] — **a deploy pauses the live host first** (Q1345, Ed 2026-09-12): CI's `POST /api/admin/pause` under `DRAFT_ADMIN_KEY` (#10), then the hook; paused, the host persists nothing, 503s commands, says `paused` on every view answer, and the page draws the maintenance modal (`noteHost`, `renderHost`). `docs/OPERATING.md` §3; guard `pause.test.ts`.
  - `surface-reload` [concept] — **a surface-only push does not restart the host** (Q1347, Ed 2026-09-12): CI packs `design/`'s served files and `POST /api/admin/surface?sha=` under `DRAFT_ADMIN_KEY` (#10); the host unpacks beside its data, serves from there, and states the commit in `x-build`. `packages/server/src/surface.ts`; `docs/OPERATING.md` §3; guard `surface.test.ts`.
  - `stalled` [symbol] — **a document whose saves the store rejects** (Q1346; any failure since #79, the command rewound): `LoadedDoc.stalled` set in `commit`, cleared by a save that lands; `stalled: true` on every view answer, `documentsStalled` in `/healthz`, and the page's red flag (`.stalledflag`). `docs/OPERATING.md` §11; guard `pause.test.ts`.
  - `load-on-demand` [concept] — **boot loads no document** (plan-scaling Stage 2, issue #219): `DocStore.open` / `openSlug` load on the first request or due tick, one load shared; `WritePath.evictIdle` unloads after `DRAFT_IDLE_MS`; `DRAFT_LOAD=eager` the old boot. Guards `load-on-demand.test.ts`, `clock-index.test.ts`, `load-walk`.
  - `RegistryRow` [symbol] — what a host knows of a document it has not loaded (Stage 2): slugs, phase, due time and both logs' lengths, from `rowOf` at an unload, checked against `docLengths` at boot and rebuilt from the constitution log when behind; `doc_registry` in Postgres, `docs/<id>/registry.json` on disk.
  - `reconnecting-bar` [concept] — **the page has lost the host** (Q1505, Ed 2026-09-23): the `offline` event, or two view polls in a row failed or unanswered (4 s each), draw a red bar under the topbar, *Reconnecting…* plus the cause where known, every commit held (`data-held`) until a poll answers. `design/live.js`; SURFACE C17; guard `scripts/repro/reconnecting.mjs`.
  - `dev-host` [concept] — dev.docs.vote: a second Render service (`draft-dev`) running the dev path — tsx, no Resend key — so the `phase-ladder`'s ⏭, the seat switch and 📬 exist at a public URL. File store on the ephemeral disk: **every deploy wipes it**, and the outbox is public, so it must never hold anything real. `docs/OPERATING.md` §9.
- `engine-bridge` [symbol] — `packages/constitution/src/engine-bridge.ts`: marries a `ConstitutionSession` to an engine-core `Session`. Text candidates go to the engine; set-motions race there and what *stands* flows back by a **standing diff** in `sync(t)`, the ground shift. **Not exported from index.ts**, so the page bundle stays engine-free. Walk: `npm run motions -w @draft/sim-harness`.
- `meaningOf` [symbol] — **what choosing a value would do, in this room**: one sentence for 👥 ⏱️ 💤 (`packages/constitution/src/meaning.ts`), fed the room as it stands. **Engine-side only since Q1439 (u)** (Ed, 2026-09-18: the meaning lines go, all three) — nothing on the page prints it; the rule sentence stands alone. Guard `meaning.test.ts`. Entries 165, 167.
- `constitution` [symbol] — **the §9 layer as a real package** (`@draft/constitution`): the 18-setting catalogue (SPEC §9.7.1 is its table), the consent rule, the blind founding, motions on both routes, the clocks on one `tick(t)`, a hash-chained log with bit-identical `replay`. **Blindness is the projection layer**, `view()`. Bundle: `design/constitution.js` (`npm run bundle`).
  - `packages/constitution/src/owed.ts` [file] — what a member is owed and the OK that answers it (Q1352 (q)): owed OKs, release batches, amendment news, mail give-up, over a snapshot of the eight fields they read; the session keeps the names as delegates, so the commands and `checkCommands` see them.
  - `packages/constitution/src/motions.ts` [file] — the motion family (Q1352 (r)): both routes, the crown, twins, the settle, over a `MotionHost` of live getters — never a snapshot, since the settle loop mints ids after emitting; the five command names stay on the session as delegates.
